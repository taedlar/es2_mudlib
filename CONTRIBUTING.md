# Contributing

## Qualifications

You are welcome here whether you are an experienced LPC developer or just getting started.

Helpful background:
- Basic familiarity with LPC is great, but not required.
- Willingness to learn the codebase and follow project conventions.
- Respectful collaboration with other community members.

Non-code contributions are also valuable, including documentation, issue triage, testing, and feedback.

## Development Setup

ES2 development is moving from in-game editing toward a Git-first workflow.
Please clone with submodules so your workspace includes both mudlib and driver sources:

```bash
git clone --recurse-submodules <repo-url>
```

The [Neolith](https://github.com/taedlar/neolith) driver is configured as a Git submodule.
This keeps repositories separate while providing a monorepo-like local code context for modern coding agents and contributors.

If you are interested in contributing to ES2 Mudlib, please contact [Annihilator](https://github.com/taedlar).
