ES2 mudlib README
=====
## Folder Structure

- *`/adm`*: Administrator workspace and priviliged LPC objects.
- *`/bin`*: Saved LPC binaries.
- *`/cmds`*: Command handlers.
- *`/d`*: Game domain and areas.
- *`/daemon`*: Global daemon objects.
- *`/data`*: Saved LPC objects.
- *`/doc`*: Mudlib documentation.
- *`/feature`*: Shared object features.
- *`/include`*: LPC include headers.
- *`/log`*: Log files.
- *`/obj`*: Stock LPC objects.
- *`/std`*: LPC object prototypes.
