管理者工作區
====
- `/adm` 這個目錄下的所有檔案和目錄必須具有系統管理者權限 `(admin)` 才允許修改。
- `/adm/etc` 儲存重要的系統設定、公告、人員權限等資料。
- `/adm/obj` 存放 ES2 核心物件實作
- `/adm/simul_efun` 存放 ES2 自定義的 API (simul_efun) 實作
- `/adm/daemons` 存放 ES2 全域的背景程序實作，非技術用語場合又稱「精靈」
- `/adm/guild` 僅限管理者和開發者(巫師)進入的遊戲區域
- `/adm/intermud` 存放支援 INTERMUD 協定的實作
